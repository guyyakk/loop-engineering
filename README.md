# Loop Engineering Starter Kit

ชุดเริ่มต้นนี้ช่วยให้ใช้ AI ทำงานวิศวกรรมแบบเป็นวงรอบ: ระบุผลลัพธ์ให้ชัด → ลงมือทำ → ตรวจด้วยหลักฐาน → แก้เฉพาะสิ่งที่ตรวจพบ → ให้คนตัดสินใจก่อนเผยแพร่

## เริ่มงานหนึ่งชิ้น

1. คัดลอก `templates/TASK_SPEC.md` ไปที่ `docs/tasks/<ชื่อสั้น ๆ>.md` แล้วกรอกให้ครบ
2. เปิดงานกับ AI coding agent ที่ใช้ (เช่น Claude Code, Codex, Cursor) โดยแนบไฟล์ spec และใช้ข้อความใน `templates/BUILD_PROMPT.md`
3. ตรวจผลลัพธ์ตาม `docs/LOOP_WORKFLOW.md` และบันทึกหลักฐานในส่วน Validation ของ spec
4. ก่อนเปิด PR ให้ใช้ `templates/REVIEW_PROMPT.md` ตรวจอีกรอบ

เริ่มจากงานเล็กที่มีเกณฑ์รับงาน 3–7 ข้อก่อน แล้วปรับกระบวนการจากผลจริงของทีม

## หลักตัดสินใจ

- การเปลี่ยนแปลงจะถือว่าสำเร็จเมื่อเกณฑ์รับงานทุกข้อมีหลักฐานรองรับ
- AI แก้ได้สูงสุด 3 รอบต่อหนึ่งงาน หากยังไม่ผ่านให้สรุป blocker และถามคน
- ห้าม deploy, merge, หรือเปลี่ยนข้อมูลจริงโดยไม่มีการยืนยันจากคน
- บันทึกคำสั่งตรวจและผลที่ได้เสมอ เพื่อให้ทำซ้ำและ review ได้
