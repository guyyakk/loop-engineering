# Task: ระบบ MOM เฟส 1 — สรุปประชุม ส่งอีเมล และสร้างรูปสำหรับ LINE จากชีตเดียว

อ้างอิงการออกแบบเต็มที่ [docs/MOM_SYSTEM_DESIGN.md](../MOM_SYSTEM_DESIGN.md)

## Outcome

ผู้จดบันทึกพิมพ์ action items ลงในฟอร์มหน้าเดียวระหว่างประชุม พอปิดประชุมกดปุ่มเดียวในเมนู "MOM" แล้วผู้เข้าร่วมได้รับอีเมลสรุปพร้อมตารางงานภายใน 1 นาที และได้ไฟล์รูป PNG หนึ่งใบสำหรับเซฟไปวางในกลุ่ม LINE เอง โดยไม่ต้องจัดรูปแบบอะไรด้วยมือ

## Context and scope

- In scope:
  - Google Sheet 3 ชีต (`meetings`, `action_items`, `people`) พร้อม data validation และ dropdown รายชื่อ
  - ฟอร์มจดประชุมหน้าเดียว (HtmlService) เป็นทางเข้าหลัก ผู้ใช้ไม่ต้องกรอกลงชีตเอง
  - Deploy เป็น Web App ลิงก์เดียว เปิดจากมือถือได้ ไม่ต้องเปิดชีตและไม่ต้องใช้เมนู
  - Apps Script: `validate()`, `buildSummary()`, `sendEmail()`, `buildImage()` และเมนู custom
  - อีเมล HTML: หัวเรื่อง มติ ตาราง action items เรียงตามกำหนดเสร็จ นัดครั้งถัดไป
  - สร้าง PNG จากเทมเพลต Google Slides เก็บใน Drive แล้วแสดงลิงก์ให้ผู้ใช้เซฟ
  - Dialog ที่มีข้อความสรุปแบบก๊อปวางได้ สำหรับคนที่อยากวางเป็นตัวหนังสือแทนรูป
  - โหมด `DRY_RUN` เป็นค่าเริ่มต้น และกันการส่งอีเมลซ้ำด้วย `status` / `sent_at`
- Out of scope:
  - LINE Messaging API / บอท / การส่งเข้ากลุ่มอัตโนมัติ (ผู้ใช้เลือกวางรูปเอง)
  - การเตือนก่อนครบกำหนดอัตโนมัติ และการอัปเดตสถานะงานจากมือถือ
  - เว็บแอป, ฐานข้อมูล, การถอดเสียงประชุม
- Constraints:
  - ไม่มีเซิร์ฟเวอร์ ใช้บัญชี Google + Apps Script เท่านั้น
  - โค้ดต้องทำงานได้ทั้งบัญชี Gmail ส่วนตัวและ Google Workspace โดยมีสวิตช์ปิดเมลรายบุคคลเมื่อโควตาไม่พอ
  - ห้าม commit รายชื่ออีเมลจริงหรือ secret ใด ๆ ลง repo
  - ห้ามส่งอีเมลออกจริงจนกว่าผู้ใช้จะยืนยัน (ตาม `AGENTS.md` ข้อ 5)

## Acceptance criteria

- [ ] กรอกชีตครบตามฟิลด์บังคับแล้วกดเมนู → ได้อีเมลสรุปที่มี action items ครบทุกแถวของประชุมนั้น เรียงตาม `due_date`
- [ ] แถวที่ `owner`, `due_date` หรือ `task` ไม่ผ่านกฎ validation ทำให้ระบบ **ไม่ส่ง** และแสดงข้อความบอกว่าแถวไหนผิดอะไร
- [ ] ได้ไฟล์ PNG ใน Drive ที่มีชื่อประชุม วันที่ `meeting_id` และงาน 5 อันดับแรกตามกำหนดเสร็จ อ่านออกบนหน้าจอมือถือ ถ้าเกิน 5 รายการต้องมีบรรทัด "และอีก N รายการ"
- [ ] กดปุ่มซ้ำในประชุมเดิม ระบบไม่ส่งอีเมลซ้ำ และแจ้งว่า "ส่งไปแล้วเมื่อ `<sent_at>`" แต่ยังสร้างรูปใหม่ได้
- [ ] เมื่อ `DRY_RUN = true` ไม่มีอีเมลออกจริง แต่มี log แสดงผู้รับและเนื้อหาที่จะส่ง และยังสร้างรูปได้ตามปกติ
- [x] จดประชุมจบได้จากฟอร์มหน้าเดียว ไม่ต้องเปิดชีตและไม่ต้องเลือก `meeting_id` เอง (ผู้ใช้ยืนยัน 2026-09-08)
- [ ] ไม่มีอีเมลจริง ชื่อจริง หรือ secret อยู่ในไฟล์ที่ commit — ค่าเหล่านี้อ่านจาก Script Properties หรือชีตทะเบียนรายชื่อเท่านั้น
