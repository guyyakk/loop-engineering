# Task: OpenLoops 8 — ผู้ช่วย AI: จดงานจากประโยค, แตกงานเป็นขั้น, จัดแผนเช้า

> spec ย่อยที่ 8 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) (v2) ต่อยอดจาก [spec 7](2026-09-25-openloops-7-calendar.md)

## Outcome

ผู้ใช้พิมพ์งานเป็นประโยคภาษาไทยธรรมดาแล้วได้ฟอร์มที่กรอกไว้ให้, ขอให้ช่วยแตกงานใหญ่เป็นขั้นที่ลงมือได้ และขอแผนเช้าที่พอดีเวลาว่างจริงพร้อมเหตุผล โดย AI เป็นแค่ผู้เสนอ ทุกอย่างผู้ใช้เห็นก่อนและกดยืนยันเอง ไม่ตั้งค่า AI แอปก็ทำงานเหมือนเดิมทุกอย่าง

## Context and scope

- In scope:
  - ส่วน "ผู้ช่วย AI" ในการตั้งค่า: ใส่ Claude API key ของผู้ใช้เอง, เลือกรุ่น, ลบ key, บอกว่าส่งข้อมูลอะไรออกไป
  - จดงานจากประโยค: ในฟอร์มจดงานใหม่ พิมพ์ประโยคที่ช่องชื่องาน แล้วกด "ให้ AI แยกรายละเอียด" → กรอกชื่องาน ทำเมื่อไหร่ กำหนดส่ง เวลาประมาณ ลักษณะงาน โปรเจกต์ ขั้นตอน
  - แตกงานเป็นขั้น: ในฟอร์ม (ทั้งจดใหม่และแก้ไข) กด "ให้ AI ช่วยแตกขั้น" → รายการขั้นที่เสนอ ติ๊กเลือกแล้วเพิ่ม
  - จัดแผนเช้า: หน้าวันนี้ กด "ให้ AI จัดแผนวันนี้" → ลำดับงานพร้อมเหตุผล, งานที่ควรดึงเข้า, งานที่ควรเลื่อน, แถบเวลาหลังใช้แผน → เลือกแล้วกด "ใช้แผนนี้" (เลิกทำได้)
- Out of scope: แชตกับ AI, ให้ AI แก้งานเองโดยไม่ถาม, เรียก AI อัตโนมัติ, เรียนรู้ตัวคูณเวลาประเมิน, ผู้ให้บริการ AI อื่น, server/proxy, เก็บลำดับที่แนะนำข้ามการรีโหลด
- Constraints:
  - ไม่มี server: เรียก Claude Messages API จาก browser ตรงด้วย key ของผู้ใช้ (header `anthropic-dangerous-direct-browser-access`)
  - key เก็บในเครื่องนี้เท่านั้น (ตาราง `local` แยกจากข้อมูลงาน) ไม่อยู่ในไฟล์สำรอง ไม่ถูกล้างตอนนำเข้าแบบแทนที่ ไม่ log
  - ส่งข้อมูลเฉพาะตอนผู้ใช้กดปุ่ม AI และส่งเฉพาะที่จำเป็นต่อคำขอนั้น
  - ผลจาก AI ต้องผ่านการตรวจก่อนใช้: วันที่ผิดรูปแบบหรือย้อนหลังทิ้ง, id งานที่ไม่มีจริงทิ้ง, งานที่ส่งวันนี้หรือเลยกำหนดห้ามเลื่อน
  - AI ทดสอบด้วย key จริงไม่ได้ (ห้ามใส่ API key แทนผู้ใช้) จึงทดสอบด้วย API จำลอง แล้วให้ผู้ใช้ทดสอบของจริง

## ค่าเริ่มต้นที่เลือก (เปลี่ยนได้)

1. ผู้ให้บริการ: Claude API ของ Anthropic, ผู้ใช้สร้าง key เองที่ console.anthropic.com และจ่ายตามการใช้
2. รุ่น: Claude Opus 5.5 เป็นค่าเริ่มต้น เลือก Sonnet 5 หรือ Haiku 4.5 ได้ถ้าอยากเร็วขึ้น/ถูกลง
3. ใช้ tool use แบบบังคับ (`tool_choice`) เพื่อให้ได้ JSON ตามโครงเสมอ

## กติกา

- จดงานจากประโยค: ส่งประโยค, วันนี้ + ปฏิทิน 14 วันข้างหน้า (วันที่ + ชื่อวัน), วันทำงาน, ชื่อโปรเจกต์ที่มี; ผลที่ได้แทนที่ชื่องานและเติมเฉพาะช่องที่ AI ระบุ; มีปุ่ม "ย้อนกลับ" คืนฟอร์มก่อนกด
- ไม่ระบุ "ทำเมื่อไหร่" แต่มีกำหนดส่ง: ส่งวันนี้ = วันนี้, ถึงวันอาทิตย์นี้ = สัปดาห์นี้, หลังจากนั้น = ไว้ก่อน
- เวลาประมาณปัดเป็นทวีคูณ 5 นาที ช่วง 5 นาที–40 ชม.; ถ้าไม่ตรงปุ่มที่มีให้แสดงเป็นปุ่มเพิ่ม
- แตกขั้น: ส่งชื่องาน โปรเจกต์ เวลาประมาณ และขั้นที่มีอยู่; ได้ 2–8 ขั้นที่ขึ้นต้นด้วยการกระทำ ไม่ซ้ำขั้นเดิม
- แผนเช้า: ส่งงานที่เปิดอยู่ (ไม่รวมงานรอคนอื่น) สูงสุด 40 งาน ด้วยรหัสสั้น (L1, L2 …) แทน id จริง พร้อมที่อยู่ (วันนี้/ลงวัน/กองงาน), สถานะ, กำหนดส่ง, เวลาที่เหลือ, ขั้นถัดไป, จำนวนครั้งที่เลื่อน, ป้ายเตือน และเวลาว่างวันนี้
- ผลแผนเช้า: ลำดับงานวันนี้ (ที่ไม่อยู่ในวันนี้ = ดึงเข้า), งานที่เลื่อนไปวันทำงานถัดไป; งานในวันนี้ที่ AI ไม่พูดถึงคงไว้; ห้ามเลื่อนงานที่ส่งวันนี้หรือเลยกำหนด
- ข้อผิดพลาดแปลเป็นภาษาไทย: key ผิด (401), ไม่มีสิทธิ์ (403), ไม่พบรุ่น (404), เครดิตไม่พอ, ถูกจำกัดความถี่ (429), ระบบ AI ไม่ว่าง (5xx/529), เครือข่าย, หมดเวลา 60 วินาที, AI ตอบไม่ครบ; กดยกเลิกระหว่างรอได้

## Remaining risk

- ยังไม่เคยเรียก Claude API จริง: คุณภาพการแยกประโยคภาษาไทย เวลาที่ใช้ และรูปแบบ error จริง (เช่น เครดิตไม่พอ) อ้างอิงจากเอกสาร ต้องยืนยันด้วย key ของผู้ใช้
- key เก็บแบบข้อความธรรมดาใน IndexedDB ของเครื่องนี้: ใครใช้ browser profile นี้ได้ก็อ่าน key ได้ และสคริปต์ที่รันใน origin เดียวกัน (เช่นสคริปต์ Google Identity เมื่อเปิดใช้ปฏิทิน) เข้าถึงได้ในทางทฤษฎี — ควรตั้งวงเงินของ key และลบ key เมื่อเลิกใช้
- ข้อมูลงาน (ชื่อ ขั้น วันที่) ถูกส่งไป Anthropic ตอนกดปุ่ม AI ถ้ามีข้อมูลลับในชื่องาน ควรเลี่ยงใช้ปุ่ม AI กับงานนั้น
- ค่าเริ่มต้นเป็นรุ่นที่แพงที่สุด (Opus 5.5) ถ้าใช้บ่อยควรเปลี่ยนเป็น Sonnet 5 หรือ Haiku 4.5
- ลำดับที่ AI แนะนำหายเมื่อรีโหลด (ตั้งใจไว้นอกขอบเขต) และงานที่ไม่ได้ประเมินเวลา AI คิดเป็น 30 นาที แต่แถบเวลาในแอปไม่นับ
