# Task: OpenLoops 10 — โหมดง่าย: รายการงาน วันนี้ / สัปดาห์นี้ / เดือนนี้ ติ๊กแล้วจางลง ย้อนดูได้

> spec ย่อยที่ 10 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) — มาจาก feedback ผู้ใช้ (2026-10-01) ว่าหน้าจอเวลาว่างรายวัน "ยังใช้ยากเกินไป"

## Outcome

เปิดแอปมาเจอรายการงานธรรมดา แบ่งเป็นแท็บ วันนี้ / สัปดาห์นี้ / เดือนนี้: พิมพ์งานแล้วกด Enter ก็เพิ่มได้ทันที เลือก "เสร็จภายใน" ได้ถ้าต้องการ ทำเสร็จก็ติ๊ก งานไม่หายแต่จางลงอยู่ท้ายรายการจนจบช่วงนั้น แล้วไปอยู่ในแท็บ "ย้อนดู" ที่บอกว่าแต่ละวันทำอะไรเสร็จไปจริง ๆ ไม่ต้องประเมินเวลาหรือดูแถบเวลาว่าง ของเดิมทั้งหมดยังอยู่ครบในโหมดละเอียด

## Context and scope

- In scope:
  - โหมดง่ายเป็นค่าเริ่มต้น: แท็บ วันนี้ (`#`), สัปดาห์นี้ (`#week`), เดือนนี้ (`#month`), ย้อนดู (`#history`)
  - ช่องเพิ่มงานบนสุดของแต่ละแท็บ + ตัวเลือก "เสร็จภายใน" (ไม่กำหนด / วันนี้ / พรุ่งนี้ / ศุกร์นี้ / สิ้นเดือน / เลือกวัน); เพิ่มเสร็จแล้วช่องว่างพร้อมพิมพ์งานต่อไป
  - ติ๊ก = เสร็จ (จางลง ขีดฆ่า มีเวลาที่ติ๊ก) ติ๊กออก = กลับมาเป็นงานค้าง
  - กดชื่องาน → แก้ชื่อ, ย้ายแท็บ, เสร็จภายใน, ลบ (เลิกทำได้)
  - แท็บย้อนดู: งานที่เสร็จจัดกลุ่มตามวันที่ติ๊ก ล่าสุดก่อน พร้อมจำนวน
  - ช่วงงานใหม่ "เดือนนี้" (`horizon: 'month'`) ใช้ได้ทั้งสองโหมด
  - ตั้งค่า: สลับ โหมดง่าย ⇄ โหมดละเอียด (เก็บใน settings และไฟล์สำรอง), ลิงก์ข้อมูลและการสำรอง
  - หน้าต่างจดงานด่วนของแอป Windows ใช้ฟอร์มแบบง่ายเมื่ออยู่ในโหมดง่าย
- Out of scope: ลบข้อมูลถาวร, แท็บแผนรายปี, งานทำซ้ำ (recurring), ลากเรียงลำดับเอง, แก้ขั้นตอนย่อยในโหมดง่าย (ขั้นเดิมยังอยู่ แสดงจำนวน)
- Constraints:
  - ไม่เปลี่ยนรูปแบบข้อมูลเดิม นอกจากเพิ่ม `'month'` และ `settings.detailed`; ไฟล์สำรองเก่ายังนำเข้าได้
  - โหมดละเอียดทำงานเหมือนเดิม (งาน "เดือนนี้" อยู่ในกอง "ไว้ก่อน" ของบอร์ดสัปดาห์)

## กติกา

- แท็บของงาน: horizon `today` → วันนี้, `week` → สัปดาห์นี้, `month` และ `later` → เดือนนี้ (งาน `later` จากโหมดละเอียดมีป้าย "ไว้ก่อน")
- งานค้างที่ถึงหรือเลยวัน "เสร็จภายใน" แล้ว ขึ้นในแท็บวันนี้ด้วย (ป้าย "จากสัปดาห์นี้/เดือนนี้") แต่ยังอยู่ในแท็บเดิม
- งานเสร็จแสดงจางในแท็บจนจบช่วง: วันนี้ = ติ๊กวันนี้, สัปดาห์นี้ = ติ๊กตั้งแต่จันทร์นี้, เดือนนี้ = ติ๊กตั้งแต่วันที่ 1 ของเดือนนี้; แท็บวันนี้รวมงานที่ขึ้นมาเพราะครบกำหนดแล้วติ๊กวันนี้ด้วย
- งานค้างในแท็บวันนี้ข้ามวันแล้วยกไปวันใหม่เหมือนเดิม ป้าย "ค้างจากเมื่อวาน" / "ค้างจาก พ. 30 ก.ย."; งานในสัปดาห์/เดือนที่สร้างก่อนช่วงนี้มีป้าย "จากสัปดาห์ก่อน" / "จากเดือนก่อน"
- เรียงงานค้าง: เลยกำหนดก่อน → เสร็จภายในใกล้สุด → ไม่กำหนด (ตามเวลาที่เพิ่ม); งานเสร็จเรียงตามเวลาที่ติ๊กล่าสุดก่อน
- ลบ = ทิ้ง (`dropped`) ไม่แสดงในโหมดง่าย มี toast เลิกทำ; ย้อนดูแสดงเฉพาะงานที่เสร็จ
- ปุ่ม N = ไปที่ช่องเพิ่มงานของแท็บปัจจุบัน

## Remaining risk

- ผู้ใช้ยังไม่ได้ลองโหมดใหม่จริง: คำ ป้าย หรือลำดับอาจต้องปรับอีกหลังใช้งาน
- แอป Windows ที่ติดตั้งจากตัวติดตั้งรุ่น spec 9 ยังเป็นหน้าจอเดิม ต้อง `npm run desktop:build` ใหม่; ไฟล์สำรองรุ่น 2 จากเว็บจะนำเข้าในแอปรุ่นเก่าไม่ได้ (แอปจะบอกให้อัปเดต)
- งานที่ "ลบ" ในโหมดง่ายยังอยู่ในฐานข้อมูลเป็นสถานะทิ้ง (ตั้งใจไม่ลบถาวร) และไม่แสดงในโหมดง่าย
- แจ้งเตือนสรุปเช้า (ถ้าเคยเปิดไว้ในโหมดละเอียด) ยังพูดถึงชั่วโมงงานตามแบบเดิม
