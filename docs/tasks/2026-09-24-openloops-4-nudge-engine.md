# Task: OpenLoops 4 — ระบบเตือน (nudge) และแจ้งเตือนบนเครื่อง

> spec ย่อยที่ 4 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) ต่อยอดจาก [spec 3](2026-09-24-openloops-3-week-board.md)

## Outcome

แอปบอกเองว่าอะไรต้องสนใจ: งานที่ต้องเริ่มวันนี้ถึงจะทัน งานที่นิ่งไปหลายวัน และงานที่ถึงวันต้องตามคนอื่น พร้อมปุ่มจัดการในคลิกเดียว และเตือนบนเครื่องวันละไม่เกิน 2 ครั้ง (เช้ากับก่อนเลิกงาน) ไม่รบกวนระหว่างทำงาน

## Context and scope

- In scope:
  - กล่อง "สิ่งที่ต้องดู" ในหน้าวันนี้ + ป้ายบนการ์ดทั้งหน้ารายการและบอร์ด
  - ร่างข้อความตามงานภาษาไทย (คัดลอกไปส่งเอง) และปุ่ม "ตามแล้ว"
  - แจ้งเตือนบนเครื่องผ่าน Notification API + service worker: สรุปเช้า, เตือนใกล้เลิกงาน, ปุ่มทดสอบ
  - ตั้งค่า: เปิด/ปิดแจ้งเตือน, เวลาเริ่มงาน, คำลงท้ายข้อความ
- Out of scope: LINE/อีเมล, push จาก server, wizard ปิดวัน (spec 5 — การแจ้งเตือนใกล้เลิกงานแค่พากลับมาที่หน้าวันนี้), โหมด focus/จับเวลา
- Constraints: ไม่มี server จึงแจ้งเตือนได้เฉพาะตอนที่แอปเปิดอยู่ (แท็บหรือหน้าต่างแอปที่ติดตั้ง จะย่อไว้ก็ได้); แอปต้องไม่ส่งข้อความหาใครเอง

## กติกา

- **เลยกำหนด**: ลูปที่ยังเปิดและกำหนดส่งก่อนวันนี้
- **ต้องเริ่มวันนี้**: ลูปที่มีกำหนดส่งและเวลาที่เหลือ คิด "วันสุดท้ายที่ต้องเริ่ม" โดยนับถอยจากวันส่งเฉพาะวันทำงาน ให้งานชิ้นเดียวใช้ได้ไม่เกินครึ่งหนึ่งของเวลาว่างต่อวัน (อย่างน้อย 30 นาที) ถ้าวันนี้ถึงหรือเลยวันนั้นแล้ว และยังไม่เลยกำหนดส่ง = ต้องเริ่มวันนี้; ลูปที่รอคนอื่นไม่นับ; กล่อง "สิ่งที่ต้องดู" แสดงเฉพาะลูปที่ยังไม่อยู่ในวันนี้ (ปุ่ม "ดึงเข้าวันนี้")
- **ถึงวันตามงาน**: ลูปที่รอคนอื่นและวันตามงาน ≤ วันนี้; "ตามแล้ว" เลื่อนวันตามงานไปอีก 3 วันทำการและนับเป็นความคืบหน้า
- **ลูปนิ่ง**: ลูปที่กำลังทำหรือติดขัด อยู่ในวันนี้หรือสัปดาห์นี้ (ไม่รวม "ไว้ก่อน") และไม่ขยับมาอย่างน้อย 3 วันทำการ
- ลำดับในกล่อง: เลยกำหนด → ต้องเริ่มวันนี้ → ถึงวันตามงาน → ลูปนิ่ง
- **แจ้งเตือนบนเครื่อง** (ปิดไว้เป็นค่าเริ่มต้น): เฉพาะวันทำงาน
  - สรุปเช้า: ตั้งแต่เวลาเริ่มงานจนถึง 30 นาทีก่อนเลิกงาน ครั้งเดียวต่อวัน
  - ใกล้เลิกงาน: ตั้งแต่ 30 นาทีก่อนเลิกงานถึง 2 ชม. หลังเลิกงาน ครั้งเดียวต่อวัน
  - เวลาเลิกงาน = เวลาเริ่มงาน + ชั่วโมงทำงาน; กันส่งซ้ำด้วย transaction ใน IndexedDB แม้เปิดหลายหน้าต่าง
