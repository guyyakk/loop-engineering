# Task: OpenLoops 2 — หน้าวันนี้ แถบเวลาว่าง และงานยกมา

> spec ย่อยที่ 2 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) ต่อยอดจาก [spec 1](2026-09-24-openloops-1-capture-and-loops.md)

## Outcome

เปิดแอปมาแล้วรู้ทันทีว่างานที่วางไว้วันนี้ใส่ลงในเวลาว่างจริงได้หรือไม่ ถ้าเกินระบบบอกว่าเกินเท่าไหร่และแนะนำว่าจะเลื่อนงานไหน งานที่ไม่เสร็จเมื่อวานถูกยกมาเองพร้อมนับว่าเลื่อนมากี่ครั้งแล้ว

## Context and scope

- In scope:
  - แผงวันนี้บนสุดของหน้า: เวลาว่างจริง, เวลาที่วางงานไว้, แถบเวลา, ข้อความสรุป
  - ตั้งชั่วโมงทำงานต่อวันและเวลาเผื่อ (ใช้ทุกวัน) และเวลาประชุม/ธุระของวันนี้ ด้วยปุ่มเลือก
  - ประเมินเวลาจากการ์ดได้ทันที, ปุ่มเลื่อนไปพรุ่งนี้, คำแนะนำงานที่ควรเลื่อนเมื่อเกินเวลา
  - ยกงานข้ามวันอัตโนมัติ + ตัวนับการเลื่อน + ป้ายบนการ์ด
  - อัปเกรดฐานข้อมูลเป็น v2 โดยข้อมูลเดิมไม่หาย
- Out of scope: ดึงประชุมจาก Google Calendar (spec 6), หน้าสัปดาห์และการลากงานลงวัน (spec 3), notification/ป้ายลูปนิ่ง/ต้องเริ่มวันนี้ (spec 4), คำถาม "ทำ / แตกย่อย / มอบหมาย / ทิ้ง" ตอนปิดวัน (spec 5), จับเวลา focus
- Constraints: เหมือน spec 1 — ใช้คนเดียว, ไม่มี server, ภาษาไทย, ใช้ปุ่มเลือกแทนการพิมพ์ตัวเลข

## กติกาการคำนวณ

- เวลาว่างจริง = ชั่วโมงทำงาน − ประชุม/ธุระวันนี้ − เวลาเผื่อ (ไม่ต่ำกว่า 0) ค่าเริ่มต้น 8 ชม. และเผื่อ 1 ชม.
- เวลาที่วางไว้ = ผลรวม "เวลาที่เหลือ" ของลูปที่เปิดอยู่ในกลุ่มวันนี้ ไม่นับลูปที่รอคนอื่น
- เวลาที่เหลือ = เวลาประเมิน × (ขั้นที่ยังไม่เสร็จ ÷ ขั้นทั้งหมด) หรือเวลาประเมินเต็มถ้าไม่มีขั้น
- สถานะ: เกิน เมื่อวางไว้ > ว่าง, ใกล้เต็ม เมื่อวางไว้ ≥ 85% ของเวลาว่าง, ไม่เช่นนั้นคือพอดี
- เลื่อนไปพรุ่งนี้ = ย้ายออกจากวันนี้ ตั้งวันแผนเป็นพรุ่งนี้ และนับการเลื่อน +1; พอถึงวันนั้นลูปกลับเข้าวันนี้เอง
- ยกข้ามวัน = ลูปในวันนี้ที่ยังไม่ปิดเมื่อขึ้นวันใหม่ นับการเลื่อน +1 ครั้งต่อการยกหนึ่งครั้ง รันซ้ำในวันเดียวกันไม่นับซ้ำ; ลูปที่รอคนอื่นยกมาแต่ไม่นับ เพราะผู้ใช้ไม่ได้เป็นคนเลื่อน
- คำแนะนำให้เลื่อน: ไม่แนะนำลูปที่ส่งวันนี้หรือเลยกำหนด ไล่จากลูปที่ไม่มีกำหนดส่งแล้วจึงส่งไกลสุด; ในกลุ่มเดียวกันเลือกตัวเล็กสุดที่ครอบคลุมส่วนที่เหลือได้ ถ้าไม่มีเลือกตัวใหญ่สุด ทำซ้ำจนครอบคลุมส่วนที่เกิน

- [x] AC5 ขึ้นวันใหม่แล้วลูปถูกยก/กลับเข้าวันนี้ตามกติกา ตัวนับไม่ซ้ำ และการ์ดแสดงป้าย "ยกมาจากเมื่อวาน" / "เลื่อนมา n ครั้ง" / "ทำพรุ่งนี้"
- [x] AC6 ฐานข้อมูลจาก spec 1 อัปเกรดเป็น v2 โดยลูปเดิมอยู่ครบ
- [x] AC7 typecheck/test/build ผ่าน และที่ 375px ไม่มี scroll แนวนอน ทั้งโหมดสว่างและมืด
