# Task: OpenLoops 3 — หน้าสัปดาห์ ลงงานรายวัน และภาระงานรายวัน

> spec ย่อยที่ 3 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) ต่อยอดจาก [spec 2](2026-09-24-openloops-2-today-view.md)

## Outcome

ผู้ใช้เห็นทั้งสัปดาห์ในหน้าเดียวว่าแต่ละวันวางงานไว้เท่าไหร่เทียบกับเวลาว่าง แล้วจัดงานลงวันได้ด้วยการลาก (บนคอม) หรือกดเลือกวัน (บนมือถือ/คีย์บอร์ด) งานที่ลงวันไว้จะเข้า "วันนี้" เองเมื่อถึงวัน และวันหยุดไม่ถูกนับเป็นวันทำงาน

## Context and scope

- In scope:
  - แท็บ "วันนี้" / "สัปดาห์" (URL `#week`), หน้าสัปดาห์จันทร์–อาทิตย์ + กองงานที่ยังไม่ลงวัน, ดูสัปดาห์หน้าได้
  - ภาระงานรายวันและเวลาประชุมรายวัน, สรุปทั้งสัปดาห์
  - ลากวาง (HTML5 drag and drop) + ตัวเลือกวันบนการ์ด, หน้ารายละเอียดของการ์ดเมื่อกดจากบอร์ด
  - ตั้งวันทำงาน, เลื่อนไปวันทำงานถัดไป, ไม่ยกงานข้ามวันในวันหยุด
  - แก้ข้อสังเกตจาก spec 2: การ์ดหุบเมื่อย้ายกลุ่ม, "เลื่อนไปพรุ่งนี้" ในวันศุกร์ได้วันเสาร์
- Out of scope: จองเวลาลงปฏิทิน/ดึงประชุมจาก Google Calendar (spec 6), ลากเรียงลำดับภายในวัน, ทบทวนสัปดาห์แบบ wizard (spec 5), notification (spec 4)
- Constraints: เหมือน spec ก่อนหน้า; ห้ามเพิ่ม library ลากวาง ใช้ HTML5 DnD ของ browser

## กติกา

- สัปดาห์เริ่มวันจันทร์ วันทำงานค่าเริ่มต้น จันทร์–ศุกร์
- เวลาว่างของวัน = ชั่วโมงทำงาน − ประชุมของวันนั้น − เผื่อ; วันหยุดเวลาว่าง = 0 และแสดงเป็น "วันหยุด" ไม่ใช่ "เกิน"
- ลงงานวันนี้ → เข้ากลุ่มวันนี้; ลงวันในอนาคต → อยู่ในวันนั้น และ `startDay` ดึงเข้าวันนี้เมื่อถึงวัน; ลงวันที่ผ่านไปแล้วไม่ได้
- ย้ายงานจากวันนี้ไปวันอื่น (ลาก, เลือกวัน หรือปุ่มเลื่อน) นับการเลื่อน +1; ย้ายระหว่างวันในอนาคต หรือย้ายกลับกองงาน ไม่นับ
- หน้ารายการ: ลูปที่ลงวันไว้ภายในสัปดาห์นี้อยู่กลุ่ม "สัปดาห์นี้" หลังจากนั้นอยู่กลุ่ม "ไว้ก่อน"
- ปุ่มเลื่อนไปวันทำงานถัดไปข้ามวันหยุด (ศุกร์ → จันทร์) และข้อความบนปุ่มบอกวันที่จริง
- วันหยุดไม่ยกงานข้ามวันและไม่นับการเลื่อน งานค้างจะถูกยกในวันทำงานถัดไปครั้งเดียว ป้ายบอกว่ายกมาจากวันไหน

## Acceptance criteria

- [x] AC1 แท็บสัปดาห์ (`#week`) แสดงจันทร์–อาทิตย์ของสัปดาห์นี้ + กองงานที่ยังไม่ลงวัน (สัปดาห์นี้ / ไว้ก่อน); วันหยุดเป็นคอลัมน์แคบ; วันที่ผ่านไปแล้วรับงานไม่ได้; เปลี่ยนไปดูสัปดาห์หน้าได้
- [x] AC2 แต่ละวันแสดงเวลาที่วางเทียบเวลาว่าง พร้อมสีพอดี/ใกล้เต็ม/เกิน/วันหยุด และจำนวนที่ปิดแล้ววันนั้น; ตั้งเวลาประชุมของแต่ละวันจากหัวคอลัมน์; มีสรุปรวมทั้งสัปดาห์
- [x] AC3 ลากการ์ดไปวางที่วันหรือกองงานได้ (กดเลิกทำได้); กดการ์ดบนบอร์ดเปิดรายละเอียดที่เลือกวันได้ด้วยปุ่ม ใช้ได้ทั้งมือถือและคีย์บอร์ด
- [x] AC4 การลงวัน/ย้ายวัน/นับการเลื่อน/การจัดกลุ่มในหน้ารายการ เป็นไปตามกติกาข้างบน
- [x] AC5 ตั้งวันทำงานได้; เลื่อนไปวันทำงานถัดไปข้ามวันหยุด; วันหยุดไม่ยกงานและไม่นับการเลื่อน; หน้าวันนี้ในวันหยุดแสดงว่าเป็นวันหยุดแทนการเตือนว่าเกิน
- [x] AC6 การ์ดที่เปิดอยู่ยังเปิดอยู่เมื่อย้ายกลุ่มหรือย้ายวัน
- [x] AC7 typecheck/test/build ผ่าน; ที่ 375px หน้าไม่มี scroll แนวนอน (บอร์ดเรียงวันลงมาเป็นรายการ) ทั้งโหมดสว่างและมืด
