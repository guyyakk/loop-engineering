# Task: OpenLoops 5 — ปิดวัน และทบทวนสัปดาห์

> spec ย่อยที่ 5 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) ต่อยอดจาก [spec 4](2026-09-24-openloops-4-nudge-engine.md)

## Outcome

จบวันด้วยการตัดสินใจกับทุกงานที่ยังเปิดในวันนี้ภายใน 2 นาที แล้วเลิกงานได้โดยไม่มีงานค้างในหัว และทุกปลายสัปดาห์เคลียร์งานที่ค้างนานพร้อมวางแผนสัปดาห์หน้าในหน้าเดียว งานที่ถูกเลื่อนซ้ำจะถูกถามตรง ๆ ว่าจะทำ แตกย่อย มอบหมาย หรือทิ้ง

## Context and scope

- In scope:
  - หน้าปิดวัน `#shutdown` แบบทีละขั้น: ทบทวนงานวันนี้ → เตรียมวันทำงานถัดไป → สรุปและปิดวัน
  - หน้าทบทวนสัปดาห์ `#review`: สรุปสัปดาห์ → เคลียร์งานค้าง → วางแผนสัปดาห์ → สรุปและบันทึก
  - ทางเข้า: ปุ่มในหน้าวันนี้และบอร์ด, ป้ายชวนทบทวนในวันทำงานสุดท้ายของสัปดาห์, แจ้งเตือนใกล้เลิกงานพาไปหน้าปิดวัน
  - แก้ข้อสังเกตจาก spec 2: คำแนะนำให้เลื่อนเลี่ยงงานที่เลื่อนซ้ำ
- Out of scope: สถิติย้อนหลังหลายสัปดาห์/กราฟ, เรียนรู้ตัวคูณการประเมินเวลา (ต้องมีการจับเวลาก่อน), ส่งข้อความหาคนที่มอบหมาย
- Constraints: ทุกการตัดสินใจบันทึกพร้อมกันตอนกดปุ่มสุดท้าย และเลิกทำได้; ยกเว้นการติ๊กขั้น ซึ่งบันทึกทันทีเพราะเป็นข้อเท็จจริงว่าทำไปแล้ว

## กติกา

- งานที่ต้องตัดสินใจตอนปิดวัน = ลูปที่เปิดอยู่ในวันนี้ ยกเว้นที่รอคนอื่น (แสดงเป็นจำนวนแยก)
- ตัวเลือกปกติ: เสร็จแล้ว / ทำต่อวันทำงานถัดไป (ค่าเริ่มต้น, นับการเลื่อน +1) / กลับกองงาน (สัปดาห์นี้ หรือ ไว้ก่อน) / ทิ้ง
- **งานที่เลื่อนซ้ำ** = เลื่อนมาแล้วอย่างน้อย 2 ครั้ง ไม่มีค่าเริ่มต้น ต้องเลือก: ทำ (ยกไปวันทำงานถัดไป) / แตกย่อย (ใส่ขั้นแรกที่ทำได้ใน 15 นาที แทรกเป็นขั้นถัดไป แล้วยกไป) / มอบหมาย (ใส่ชื่อ → รอคนอื่น ตามงานอีก 3 วันทำการ) / ทิ้ง
- ทบทวนสัปดาห์ — งานค้างที่ต้องเคลียร์ = ลูปที่เปิดอยู่ ไม่ได้รอคนอื่น และ (เลยกำหนด หรือ นิ่ง ≥ 3 วันทำการ หรือ เลื่อนมาแล้ว ≥ 3 ครั้ง); ตัวเลือก: ทำต่อ (ไม่เปลี่ยน) / แตกย่อย / มอบหมาย / ไว้ก่อน / ทิ้ง
- วางแผนสัปดาห์ = ลูปในกองงาน (สัปดาห์นี้ไม่ระบุวัน และไว้ก่อน) เลือกวันทำงานของสัปดาห์เป้าหมาย / ไว้ก่อน / ทิ้ง / ไม่เปลี่ยน; สัปดาห์เป้าหมายค่าเริ่มต้น = สัปดาห์หน้า ถ้าวันนี้พฤหัสบดีขึ้นไป ไม่เช่นนั้นสัปดาห์นี้ (สลับได้)
- ป้ายชวนทบทวนสัปดาห์แสดงในหน้าวันนี้ ตั้งแต่วันทำงานสุดท้ายของสัปดาห์จนจบสัปดาห์ ถ้ายังไม่ได้ทบทวนสัปดาห์นั้น
- คำแนะนำให้เลื่อน (spec 2) เลือกงานที่เลื่อนมาไม่ถึง 2 ครั้งก่อน ใช้งานที่เลื่อนซ้ำเฉพาะเมื่อไม่พอ

## Acceptance criteria

- [x] AC1 หน้าปิดวันขั้นแรกแสดงงานวันนี้ทีละรายการพร้อมตัวเลือกปกติ (ค่าเริ่มต้น ทำต่อ) และติ๊กขั้นที่ทำแล้วได้; งานที่รอคนอื่นแสดงเป็นจำนวน

- [x] AC3 ขั้นเตรียมวันถัดไปแสดงภาระงานของวันทำงานถัดไปตามการตัดสินใจ (เตือนถ้าเกิน); ขั้นสุดท้ายสรุปผลและจดโน้ตได้; กด "ปิดวัน" แล้วบันทึกทุกอย่างพร้อมกัน เลิกทำได้ และหน้าวันนี้บอกว่าปิดวันแล้ว
- [x] AC4 หน้าทบทวนสัปดาห์สรุปงานที่ปิดในสัปดาห์ (จำนวน เวลา ชื่องาน) จำนวนวันที่ปิดวัน และงานที่เลื่อนบ่อย; เคลียร์งานค้างตามกติกา
- [x] AC5 วางแผนสัปดาห์: เลือกวันให้งานในกองงานด้วยปุ่ม เห็นภาระงานรายวันของสัปดาห์เป้าหมายเปลี่ยนทันที; บันทึกพร้อมกันตอนจบ เลิกทำได้
- [ ] AC6 ทางเข้าครบ (ปุ่มปิดวัน, ปุ่มทบทวนสัปดาห์, ป้ายชวนทบทวนในวันทำงานสุดท้าย, แจ้งเตือนใกล้เลิกงานเปิด `#shutdown`); ใช้ได้ด้วยคีย์บอร์ดทั้งหมด
- [x] AC7 คำแนะนำให้เลื่อนเลี่ยงงานที่เลื่อนซ้ำ; typecheck/test/build ผ่าน; ที่ 375px ไม่มี scroll แนวนอน ทั้งโหมดสว่างและมืด
