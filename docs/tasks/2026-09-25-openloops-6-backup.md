# Task: OpenLoops 6 — สำรองและย้ายข้อมูลด้วยไฟล์

> spec ย่อยที่ 6 ของ [2026-09-24-openloops-0-epic.md](2026-09-24-openloops-0-epic.md) แทรกก่อน v2 ตามที่ผู้ใช้ขอ หลังเห็นข้อมูลใน browser หายจริงระหว่างทำ [spec 5](2026-09-24-openloops-5-rituals.md)

## Outcome

ผู้ใช้ดาวน์โหลดไฟล์สำรองของงานทั้งหมดได้ในคลิกเดียว และนำไฟล์นั้นกลับมาใช้ได้ ทั้งในเครื่องเดิมหลังข้อมูลหาย หรือในเครื่อง/browser ใหม่ โดยการนำเข้าต้องไม่ทำให้ข้อมูลเดิมพังหรือหายโดยไม่ตั้งใจ และแอปคอยเตือนให้สำรองเป็นประจำ

## Context and scope

- In scope:
  - หน้า "ข้อมูลและการสำรอง" (`#data`): ส่งออก, นำเข้า (รวม / แทนที่), สถานะการสำรองและการเก็บข้อมูลของ browser
  - ป้ายเตือนให้สำรองในหน้าวันนี้ และปุ่มสำรองในขั้นสรุปของทบทวนสัปดาห์
  - ทางเข้าจากส่วนตั้งค่าในแผงวันนี้ และท้ายหน้า
- Out of scope: sync อัตโนมัติ/คลาวด์, เข้ารหัสไฟล์, สำรองอัตโนมัติตามเวลา (browser ไม่ให้เขียนไฟล์เองโดยไม่มีการกด), นำเข้าจากแอปอื่น (CSV/Todoist)
- Constraints: ไม่มี server; ไฟล์เป็น JSON อ่านได้; นำเข้าต้องตรวจทั้งไฟล์ก่อน ถ้าผิดตรงไหนต้องไม่แตะข้อมูลเดิมเลย; ทุกการนำเข้าเลิกทำได้

## กติกา

- ไฟล์ชื่อ `openloops-backup-YYYY-MM-DD.json` มี `app: "openloops"`, `format: 1`, `exportedAt`, งานทั้งหมด (รวมที่ปิดแล้ว), ข้อมูลรายวัน และการตั้งค่า
- นำเข้าปฏิเสธพร้อมบอกเหตุผล เมื่อ: ไม่ใช่ JSON, ไม่ใช่ไฟล์ของ OpenLoops, มาจากรุ่นที่ใหม่กว่า, งานหรือข้อมูลรายวันไม่ครบ, id ซ้ำ, ไฟล์ใหญ่เกิน 10 MB
- ฟิลด์ที่ไม่บังคับและไม่มีในไฟล์ (เช่น ไฟล์จากรุ่นเก่า) ใช้ค่าเริ่มต้น
- **รวม** (ค่าเริ่มต้น): งานที่ยังไม่มีเพิ่มเข้า; งานที่มีอยู่แล้วใช้ฉบับที่แก้ล่าสุด (`updatedAt`); ข้อมูลรายวันเติมเฉพาะวันที่ยังไม่มี; การตั้งค่าคงเดิม
- **แทนที่**: ล้างแล้วใส่ข้อมูลจากไฟล์ทั้งหมดรวมการตั้งค่า ต้องกดยืนยันครั้งที่สอง
- หลังนำเข้ามี toast เลิกทำ 15 วินาที ซึ่งคืนข้อมูลทั้งหมดกลับเป็นก่อนนำเข้า
- ป้ายเตือนให้สำรอง: ไม่เคยสำรองและมีงานอย่างน้อย 5 งาน หรือสำรองล่าสุดเกิน 7 วัน; กด "ไว้ทีหลัง" ซ่อนถึงพรุ่งนี้

## Acceptance criteria

- [x] AC1 ส่งออก: ดาวน์โหลดไฟล์ตามกติกาได้ในคลิกเดียว ข้อมูลครบทั้งงานที่ปิดแล้ว ข้อมูลรายวัน และการตั้งค่า; บันทึกเวลาสำรองล่าสุดและแสดงในหน้าข้อมูล
- [x] AC2 นำเข้า: ตรวจไฟล์ตามกติกา ถ้าผิดบอกเหตุผลเป็นภาษาไทยและข้อมูลเดิมไม่เปลี่ยน; ถ้าถูกแสดงสรุปก่อนยืนยัน (จำนวนงาน เปิด/ปิด วันที่สำรอง และผลที่จะเกิดในโหมดรวม)
- [x] AC3 โหมดรวมและโหมดแทนที่ทำงานตามกติกา; แทนที่ต้องยืนยันครั้งที่สอง; นำเข้าแล้วเลิกทำได้
- [x] AC4 round-trip: ส่งออกแล้วนำเข้าในฐานข้อมูลว่าง (เครื่องใหม่) ได้ข้อมูลเหมือนเดิมทุกฟิลด์
- [x] AC5 เตือนให้สำรองตามกติกา; ขั้นสรุปของทบทวนสัปดาห์มีปุ่มสำรอง; หน้าข้อมูลบอกว่า browser เก็บข้อมูลแบบถาวรหรือไม่
- [x] AC6 typecheck/test/build ผ่าน; ที่ 375px ไม่มี scroll แนวนอน ทั้งโหมดสว่างและมืด
