# Epic: OpenLoops — planner ที่ไม่ยอมให้งานค้างกลางทาง (ร่าง)

> สถานะ: **กำลังทำ** — spec 1–6 เสร็จ (MVP ครบ พร้อมการสำรองข้อมูล) — spec หลักตัวนี้เป็นตัวเชื่อมไปยัง spec ย่อยเท่านั้น ตามหัวข้อ "Scale" ใน [LOOP_WORKFLOW.md](../LOOP_WORKFLOW.md) จึงไม่มี acceptance criteria ของตัวเอง

## Outcome

ผู้ใช้เปิดเครื่องมาแล้วรู้ภายใน 10 วินาทีว่า วันนี้ต้องทำอะไร งานไหนค้างกลางทางอยู่ขั้นไหน และแผนวันนี้ใส่เข้าไปในเวลาว่างจริงได้หรือไม่ พอจบวันก็ไม่มีงานไหนหายไปเฉย ๆ โดยไม่ถูกปิด เลื่อน หรือทิ้งอย่างตั้งใจ

## แก่นของไอเดีย

1. **หน่วยของงานคือ "ลูป" ไม่ใช่ checkbox** — ลูปหนึ่งมีหลายขั้น (process) มีสถานะ `กำลังทำ / รอคนอื่น / ติดขัด / เสร็จ / ทิ้ง` และมี "ขั้นถัดไป" เสมอ
2. **วางแผนตามเวลาว่างจริง** — เวลาว่าง = ชั่วโมงทำงาน − ประชุม − เผื่อ ถ้าวางงานเกินให้เห็นทันทีและเสนอว่าจะเลื่อนอะไร
3. **เตือนตอนต้องเริ่ม ไม่ใช่ตอนครบกำหนด** — คำนวณวันสุดท้ายที่ต้องเริ่ม จากกำหนดส่ง, งานที่เหลือ และเวลาว่างต่อวัน
4. **ทุกลูปต้องปิดอย่างตั้งใจ** — ปิดวันทุกเย็นและทบทวนสัปดาห์ทุกวันศุกร์ งานที่เลื่อนซ้ำจะถูกถามตรง ๆ ว่า ทำ / แตกย่อย / มอบหมาย / ทิ้ง
5. **เรียนรู้จากตัวเอง** — เก็บเวลาที่ประเมินเทียบกับเวลาจริง แล้วปรับตัวคูณการประเมินให้อัตโนมัติ

## กฎการเตือน (ร่าง)

| ประเภท | เงื่อนไข | ช่องทาง |
| --- | --- | --- |
| สรุปเช้า | เวลาเริ่มงานที่ตั้งไว้ | notification 1 ครั้ง |
| ต้องเริ่มวันนี้ | `วันนี้ >= latest_start` และลูปยังไม่เริ่ม | ป้ายแดงในหน้าวันนี้ + notification |
| ลูปนิ่ง | `now - last_progress_at > stall_days` (ค่าเริ่มต้น 3 วันทำงาน) | ป้ายเหลือง |
| ถึงเวลาตามงาน | ลูปสถานะ "รอคนอื่น" และถึง `follow_up_at` | ป้ายฟ้า + ร่างข้อความตามงาน |
| วางงานเกินเวลา | `sum(estimate) > free_capacity` | แถบเวลาเป็นสีแดง |
| ปิดวัน | 30 นาทีก่อนเลิกงาน | notification 1 ครั้ง |

เงื่อนไขทุกข้อต้องรวมเป็นชุดเดียว (batch) และเคารพช่วงเวลาห้ามรบกวนกับโหมด focus

## โครงข้อมูลหลัก (ร่าง)

- `Loop`: title, project, steps[], current_step, status, next_action, due_at, estimate_remaining, horizon (`today` / `week` / `later`), waiting_on, follow_up_at, last_progress_at, rollover_count, energy (`deep` / `shallow`)
- `Step`: title, estimate, done_at
- `DayPlan`: date, capacity_minutes, committed_loop_ids, shutdown_at, note
- `TimeEntry`: loop_id, started_at, ended_at
- `Template`: ชื่อ process ที่ทำซ้ำ และรายการขั้นเริ่มต้น

ผู้ใช้ต้องไม่ต้องกรอกโครงนี้ตรง ๆ ทางเข้าหลักเป็นฟอร์มจดเร็วและปุ่มเลือก
