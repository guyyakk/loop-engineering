# รายการที่รอคนตรวจ

ทุกข้อที่ AI ตรวจเองไม่ได้ (บัญชีจริง, key จริง, สิทธิ์ของ browser/OS, ติดตั้งโปรแกรม, tray/แจ้งเตือนจริง) จากทุก spec รวมไว้ที่นี่ที่เดียว

วิธีใช้:

1. ทดสอบตามขั้นตอนแล้วติ๊กข้อที่ผ่าน
2. ติ๊กเกณฑ์เดียวกันใน spec ต้นทาง และเปลี่ยน `Status:` ของ spec เป็น `เสร็จ` เมื่อไม่เหลือข้อค้าง (spec ที่เขียนก่อน 2026-10-29 ยังไม่มีบรรทัด `Status:` ให้เพิ่มไว้ใต้ชื่อ spec ตอนนั้น)
3. ถ้าไม่ผ่าน ให้จดสั้น ๆ ใต้ข้อนั้นว่าเห็นอะไร แล้วเปิดเป็น spec แก้ไขใหม่

CI ตรวจว่ารายการนี้ตรงกับ spec ทั้งสองทาง (`node scripts/check-docs.mjs`): ถ้าติ๊กที่นี่แล้วลืมติ๊กใน spec หรือกลับกัน CI จะไม่ผ่านและบอกว่าข้อไหน — ข้อใหม่ต้องมีรหัสเกณฑ์ (เช่น **S4-AC4** หรือ **AC3**) และลิงก์ไปที่ spec ต้นทาง

รวบรวมย้อนหลังจาก spec 4–10 เมื่อ 2026-10-29 — ถ้าเคยทดสอบข้อไหนไปแล้วติ๊กได้เลย
คำสั่งทั้งหมดรันในโฟลเดอร์ `apps/openloops`

## OpenLoops บน browser (Chrome หรือ Edge)

เตรียม: `npm run build && npm run preview` แล้วเปิด http://localhost:4173

- [ ] **S4-AC4** แจ้งเตือน: เปิด/ทดสอบ/สถานะสิทธิ์ — [spec 4](tasks/2026-09-24-openloops-4-nudge-engine.md)
  - "ตั้งเวลาและการแจ้งเตือน" → "เปิดแจ้งเตือน" → กดอนุญาตในหน้าต่างของ browser
  - ควรเห็นสถานะ "อนุญาต" แล้วกด "ทดสอบ" → มีแจ้งเตือนขึ้นมุมจอ
- [ ] **S4-AC5** แจ้งเตือนจริงตามเวลา และกดแล้วกลับมาที่แอป — [spec 4](tasks/2026-09-24-openloops-4-nudge-engine.md)
  - ทดสอบในวันทำงาน โดยเปิดแอปค้างไว้ (แท็บ browser ต้องเปิดอยู่)
  - สรุปเช้า: ส่งครั้งเดียวต่อวัน ตั้งแต่เวลาเริ่มงานจนถึง 30 นาทีก่อนเลิกงาน — ถ้าวันนี้ยังไม่เคยได้ ตั้งเวลาเริ่มงานให้เป็นเวลาก่อนหน้าตอนนี้เล็กน้อยแล้วรอไม่เกิน 1–2 นาที
  - ครั้งที่สองของวันเดียวกันต้องไม่ขึ้นซ้ำ
  - กดที่แจ้งเตือน → หน้าต่าง OpenLoops ขึ้นมาด้านหน้า
- [ ] **S5-AC6** กดแจ้งเตือนใกล้เลิกงานแล้วเปิดหน้าปิดวัน — [spec 5](tasks/2026-09-24-openloops-5-rituals.md)
  - เตือนใกล้เลิกงานขึ้นตั้งแต่ 30 นาทีก่อนเลิกงาน (เวลาเริ่มงาน + ชั่วโมงทำงาน) จนถึง 2 ชั่วโมงหลังเลิกงาน ครั้งเดียวต่อวัน
  - กดที่แจ้งเตือน → แอปเปิดที่ `#shutdown` (หน้าปิดวัน)
- [ ] **S7-AC1** เชื่อม Google Calendar ด้วยบัญชีจริง — [spec 7](tasks/2026-09-25-openloops-7-calendar.md)
  - สร้าง OAuth Client ID ใน Google Cloud Console ตามขั้นตอนที่แสดงในแอป
  - "ตั้งเวลาและการแจ้งเตือน" → Google Calendar → ใส่ Client ID → "เชื่อมต่อ Google Calendar"
  - Google ต้องขอแค่สิทธิ์ "ดูข้อมูลว่าง/ไม่ว่าง"; หลังอนุญาตแถบเวลาวันนี้มีส่วน "ปฏิทิน" ตรงกับนัดในเวลางาน
  - กด "ตัดการเชื่อมต่อ" → สถานะกลับเป็นพร้อมเชื่อมต่อ
- [ ] **S8-AC1** ใส่ Claude API key จริงผ่านช่องในแอป — [spec 8](tasks/2026-09-25-openloops-8-ai-assist.md)
  - สร้าง key ที่ console.anthropic.com และตั้งวงเงินใช้จ่าย
  - "ตั้งเวลาและการแจ้งเตือน" → ผู้ช่วย AI → วาง key → บันทึก → ขึ้น "พร้อมใช้ · key sk-ant-…" (ไม่แสดง key เต็ม)
- [ ] **S8-AC5** เรียก Claude API จริงครบ 3 ความสามารถ — [spec 8](tasks/2026-09-25-openloops-8-ai-assist.md)
  - กด N พิมพ์งานเป็นประโยค → "ให้ AI แยกรายละเอียด" → ฟอร์มถูกกรอก
  - ในฟอร์มกด "ให้ AI ช่วยแตกขั้น" → ได้ขั้นให้ติ๊ก
  - หน้าวันนี้กด "ให้ AI จัดแผนวันนี้" → ได้ลำดับพร้อมเหตุผล
  - ถ้า error ข้อความต้องเป็นภาษาไทยและเข้าใจได้

## OpenLoops แอป Windows

เตรียม: `npm run desktop:build` (ตัวติดตั้งรุ่นเก่าไม่อยู่ในเครื่องแล้ว และรุ่น spec 9 ยังไม่มีโหมดง่ายของ spec 10) แล้วติดตั้งจาก `src-tauri/target/release/bundle/nsis/OpenLoops_0.1.0_x64-setup.exe` — Windows SmartScreen จะเตือนเพราะยังไม่เซ็นรับรอง

- [ ] **S9-AC2** tray และการปิดหน้าต่าง — [spec 9](tasks/2026-09-25-openloops-9-desktop.md)
  - มีไอคอน OpenLoops ที่ tray; คลิกขวาเห็นเมนู เปิด / จดงานด่วน / ออก
  - กดปิดหน้าต่าง → หน้าต่างหายแต่ไอคอนยังอยู่; เปิดแอปซ้ำ → กลับมาหน้าต่างเดิม
- [ ] **S9-AC3** Ctrl+Alt+N จดงานด่วน — [spec 9](tasks/2026-09-25-openloops-9-desktop.md)
  - เปิดโปรแกรมอื่นอยู่ กด Ctrl+Alt+N → หน้าต่างจดงานด่วนขึ้น พิมพ์งาน + Enter
  - หน้าต่างหลักเห็นงานใหม่ทันที; กด Ctrl+Alt+N อีกครั้งแล้ว Esc → ปิดโดยไม่บันทึก
- [ ] **S9-AC4** แจ้งเตือนของ Windows ตอนหน้าต่างถูกซ่อน — [spec 9](tasks/2026-09-25-openloops-9-desktop.md)
  - ปุ่มทดสอบในการตั้งค่า → แจ้งเตือนขึ้นโดยชื่อแอปเป็น OpenLoops
  - ซ่อนหน้าต่างไว้แล้วรอสรุปเช้า/เตือนปิดวัน → ยังขึ้นตามเวลา
- [ ] **S9-AC5** เปิดพร้อม Windows — [spec 9](tasks/2026-09-25-openloops-9-desktop.md)
  - ส่วนแอป Windows ในการตั้งค่าแสดงสถานะปุ่มลัด; เปิดสวิตช์เปิดพร้อม Windows
  - รีสตาร์ตเครื่อง → แอปเริ่มเองแบบซ่อน (มีแค่ไอคอนที่ tray)
