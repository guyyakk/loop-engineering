# Prompt: Build loop

ใช้ข้อความนี้หลังสร้าง task spec แล้ว

```text
ทำงานตาม task spec ที่ [พาธไฟล์ spec]

เป้าหมายคือทำให้ acceptance criteria ทุกข้อผ่านด้วยหลักฐานจริง

ก่อนแก้โค้ด ให้สรุป outcome, ขอบเขต, เกณฑ์รับงาน, ไฟล์ที่คาดว่าจะเปลี่ยน และคำสั่งตรวจที่เหมาะกับ repository นี้
จากนั้นทำ implementation ที่เล็กที่สุดที่ตอบโจทย์ และรัน validation ที่เกี่ยวข้อง

หากการตรวจไม่ผ่าน ให้แก้ตามผลที่พบแล้วตรวจซ้ำ โดยแก้ได้สูงสุด 3 รอบ
อัปเดตตาราง Validation plan และ Loop log ใน spec ทุกครั้ง

ห้าม merge, deploy, เปิด PR หรือแก้ข้อมูลจริงเอง
เมื่อเสร็จ ให้สรุปไฟล์ที่เปลี่ยน, ผลตรวจราย acceptance criterion, ความเสี่ยงคงเหลือ และสิ่งที่ต้องให้คนตัดสินใจ
```
