# Prompt: Review loop

ใช้กับ diff หรือ PR หลัง build loop ผ่านแล้ว

```text
Review การเปลี่ยนแปลงนี้เทียบกับ task spec ที่ [พาธไฟล์ spec]

มองหาข้อผิดพลาดที่ทำให้พฤติกรรมผิด, regression, edge case, ช่องโหว่/การรั่วไหลของข้อมูล, การขาด test และ acceptance criteria ที่ยังไม่มีหลักฐาน
อย่าแก้โค้ดจนกว่าจะสรุป review เสร็จ

รายงานเฉพาะข้อพบที่นำไปแก้ได้ โดยระบุระดับความสำคัญ, ไฟล์/ตำแหน่ง, ผลกระทบ และแนวทางแก้
หากไม่พบปัญหา ให้ระบุสิ่งที่ตรวจแล้ว และรายการความเสี่ยงที่ยังตรวจไม่ได้
```
